# AI Agent Configuration for Desafio Fullstack

> Configuration and capabilities for AI-assisted full-stack development.

## 🤖 Agent Capabilities

### Code Understanding
- **Node.js/Express**: Routing, middleware, async operations
- **Vue.js/React/Angular**: Components, state management, forms
- **PostgreSQL**: Schema design, queries, relationships
- **REST API**: HTTP methods, status codes, request/response
- **Form Validation**: Frontend and backend validation patterns
- **Pagination**: Offset/limit, page calculations
- **Error Handling**: Proper error responses and user feedback

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Creating Express routes and controllers
- Implementing CRUD operations
- Building PostgreSQL schema and migrations
- Creating React/Vue/Angular pages and components
- Implementing form validation (frontend + backend)
- Pagination and filtering logic
- API client service layer
- Error handling and logging
- Responsive UI with Tailwind/Bootstrap
- Testing with Jest/Vitest
- Docker containerization
- API documentation with Swagger

❌ **Not Recommended**:
- Bypassing server-side validation
- Hardcoding sensitive configuration
- Direct database queries without parameterization (SQL injection risk)
- Complex frontend state management without clear architecture
- Skipping error handling and edge cases

## 🛠 Recommended Skills

### Skill 1: Express Backend Setup
**When**: Building API endpoints
**Process**:
1. Create Express app with middleware
2. Connect to PostgreSQL
3. Create table schema
4. Implement routes with proper HTTP methods
5. Add validation middleware
6. Return consistent response format

### Skill 2: CRUD Page Components
**When**: Building frontend (React/Vue/Angular)
**Process**:
1. Create List page with table
2. Create Form page (reuse for create/edit)
3. Wire API client service
4. Handle loading/error states
5. Implement pagination controls
6. Add success/error notifications

### Skill 3: Pagination & Filtering
**When**: Adding list features
**Process**:
1. Backend: Accept page, limit, search params
2. Calculate OFFSET = (page - 1) * limit
3. Query with WHERE + LIMIT + OFFSET
4. Return total count
5. Frontend: Display pagination controls
6. Frontend: Update page on control click

## 🔑 Key Concepts

- **3-Tier Architecture**: Presentation, Business Logic, Data layers
- **REST Principles**: Resource-based URLs, HTTP methods
- **Pagination**: Offset/limit for large datasets
- **Validation**: Sanitize and validate all inputs
- **Error Handling**: Proper status codes and error messages
- **Database Indexing**: Optimize filtering performance
